# Fluid Identity — 사진영상정리기

사진과 영상을 폴더째로 빠르게 보고, **칩**으로 분류하고, 중복을 걸러내는 로컬 정리 도구예요.
파일은 내 PC에만 있고 어디에도 올라가지 않아요. 칩·메모·별점 같은 정리 정보는 사진 폴더 안
`.fluid-organizer` 폴더에 함께 저장돼서, 브라우저나 PC를 다시 깔아도 그대로 남아요.

## 여는 방법

| 방법 | 이렇게 하세요 | 이런 때 |
|---|---|---|
| **바로 열기** | `사진영상정리기.html`을 Chrome이나 Edge로 열고 **작업 폴더 열기** (Ctrl+O) | 설치 없이 바로 쓸 때 |
| **로컬 서버로 열기** | `server\start.bat`을 한 번 실행 → 다음부터는 **바탕화면의 사진영상정리기 아이콘**만 누르면 돼요 | HEIC·TIFF 썸네일, AVI·WMV·MTS 재생, 큰 영상 자르기·합치기, 다른 드라이브 폴더 중복검사, 탐색기에서 보기가 필요할 때 |

- 로컬 서버는 이 PC 안에서만 도는 도우미예요. 사진·영상은 어디에도 올라가지 않아요.
- 처음 한 번은 구성 요소를 내려받느라 몇 분 걸려요. 그 뒤로는 아이콘을 누르면 서버와 앱이 함께 켜지고 마지막 작업 폴더가 열려요.
- 바로 열기로 쓰다가 서버를 켜면 **‘서버로 계속하기’** 한 번으로 같은 폴더 그대로 넘어가요. 자세한 내용은 `server/README.md`.
- 하나의 HTML 파일로 들고 다니고 싶으면 `npm run build` → `dist/사진영상정리기.html`.

## 무엇을 할 수 있나요

**폴더**
- 왼쪽 폴더 트리: 우클릭으로 새 폴더·이름 바꾸기·휴지통·폴더 풀기·즐겨찾기, 끌어다 놓아 이동(Ctrl은 복사), 폴더 위에 머물면 열림
- 폴더마다 사진·영상·폴더 개수와 전체 용량, 빈 폴더 표시
- 즐겨찾기(Ctrl+D), 뒤로·앞으로·위로(Alt+←/→/↑), 경로 표시줄의 하위 폴더 메뉴, 초성 검색(ㄱㅅㅎ → 김수현)
- 한 번 연 폴더와 라이브러리는 다음부터 바로 열려요(2만 장 폴더도 0.1초 안). 뒤에서 바뀐 부분만 다시 확인하고, F5는 지금 바로 확인
- 같은 작업 폴더를 창 두 개로 열면 나중 창은 ‘보기 전용’이 돼서 정리 정보가 엉키지 않아요(‘여기서 이어서 하기’로 넘겨받기)

**갤러리**
- 수만 장도 부드러운 가상 스크롤, 썸네일 크기(Ctrl+휠), 격자/목록 보기(Ctrl+Shift+L)
- 마우스를 올린 영상만 소리 없이 재생(Shift를 누른 채 움직이면 장면 넘겨 보기). 뒤에서 목록이 바뀌어도 멈추지 않아요
- 드래그 범위 선택, Ctrl/Shift 선택(폴더도), 복사·잘라내기·붙여넣기(Ctrl+C/X/V), Space로 훑어보기 — 썸네일을 만드는 중에도 클릭이 사라지지 않아요
- 뒤에서 정렬이 바뀌면 화면은 그대로 두고 알려 줘요(Alt+G = 선택한 곳으로)

**칩 (분류)**
- 칩 세트 → 분류(선택형/검색형) → 칩 → 하위 칩으로 나눠요. 배우 이름처럼 많은 건 검색형으로 써요
- **칩 세트는 프로그램 전체에서 함께 써요.** 작업 폴더마다 마지막으로 쓰던 세트를 기억해요. 칩 패널 맨 위에 세트 이름이 있고, 누르면 바꾸기·만들기·복제·이름 바꾸기를 할 수 있어요
- 세트 메뉴의 **이 세트를 파일로 내보내기**로 `.chipset.json` 파일을 저장하고, **세트 파일 불러오기…**로 가져와요. 같은 ID의 세트가 있으면 바꿀지 물어봐요. 세트 삭제는 모든 작업 폴더에 적용되고, 파일에서 칩을 떼는 작업은 현재 작업 폴더에만 적용해요
- 분류 제목을 누르면 접거나 펼쳐요(키보드는 Enter/Space). 접은 상태를 기억하고, Ctrl+Z로 되돌릴 수 있어요
- 여러 파일에 한 번에 붙이기, 숫자 1~9로 칩 단축키, `#`으로 칩 찾기(초성 검색) — 없는 이름을 쓰고 Enter면 새 칩을 만들어 바로 붙여요
- 보기 화면에서도 다 돼요: `#`·1~9, 위쪽 **칩** 버튼(Alt+C)을 누르면 **오른쪽에 칩 패널 자리**가 생겨요(사진·영상은 옆으로 비켜요). 칩 붙이기·새 칩·**분류 추가**까지 화면을 떠나지 않고. 한 번 열어 두면 다음에도 열려 있어요
- **완료하고 다음**(보기 화면에서 Ctrl+Enter)을 누르면 파일 전체를 작업 폴더의 **`_완료` 폴더**로 옮기고 다음 파일을 열어요. 하위 폴더 구조와 정리 정보도 따라가요. 조각을 골랐어도 파일 전체를 완료해요. 갤러리 우클릭으로 여러 파일을 완료할 수도 있어요. **완료함**에서 모아 보고, Ctrl+Z 한 번으로 이동을 되돌려요
- 사이드바 칩 필터(그리고/또는/빼기), **모든 폴더에서 보기**, **미분류** 보기를 써요. 남아 있는 영상 조각의 칩도 필터에 포함돼요. 파일 칩만으로 조건을 만족하지 못하면 카드에 **조각 n** 배지가 뜨고, 열 때 조건에 기여한 첫 조각부터 재생해요
- 별점(Ctrl+Alt+0~5), 색상 라벨(Ctrl+Alt+6~9), 오른쪽 아래 메모

**보기 화면** (Enter / 더블클릭)
- 확대·이동(Ctrl+휠), 회전(R / Shift+R), 좌우·상하 반전(H / V) — 원본은 그대로 두고, 원하면 파일에 적용
- 영상: ←/→ 건너뛰기, ↑/↓ 소리, J/K/L 속도, 프레임 이동(, .), 구간 반복(A), 마커(B), 장면 캡처(C), 대표 장면(Shift+C)
- 필름 띠(T), 정보(I), 슬라이드쇼(S)

**영상 편집 — 보기 화면에서 바로** (따로 여는 창 없음, 재생바가 곧 편집 트랙)
- **Q** 재생 위치 앞부분 날리기 · **W** 뒷부분 날리기 · **Ctrl+B** 그 자리에서 자르기(면도날). 잘라낸 부분은 빗금으로 보여요
- 오른쪽 패널은 **칩 | 메모 목록** 탭으로 오가요(Alt+C / Shift+B)
- 재생바의 조각을 클릭 → 바로 위에 메모(#태그)·칩 칸. Delete로 조각 빼기/되살리기, 경계선은 끌어서 조정
- **조각을 고른 동안엔 `#`·1~9·칩 패널이 그 조각에 칩을 붙여요**(없는 칩은 그 자리에서 만들어요). Esc로 조각 선택을 풀면 영상 전체에 붙어요
- **P** 편집본 미리보기(잘라낸 부분 건너뛰기) · **Shift+B** 메모 목록(마커+조각) · **E** 편집 단축키 보기
- **Shift+S** 저장: 남은 부분 이어서 새 파일 / 조각마다 새 파일 / 보관함에 담기. 원본은 그대로예요. MP4·WebM은 서버 없이도 무손실로 저장(키프레임 기준이라 앞이 조금 더 남을 수 있어요), 그 밖의 형식은 로컬 서버
- **G** 보는 중에 ‘방금 장면’(앞 15초~뒤 5초)을 보관함에 바로 담기 — 멈추지 않아요
- 조각 메모의 #태그와 마커 메모도 검색에 걸려요. 모든 편집은 Ctrl+Z로 하나씩 되돌려요

**보관함** (왼쪽 사이드바, Alt+B)
- 잘라 담은 조각을 모아 보고 메모·칩을 달아요. 초성 검색, 칩으로 거르기, 끌어서 순서 바꾸기
- 클릭하면 그 구간만 반복 재생, **이어 보기**로 여러 조각을 차례로 — 칩 하나 누르고 이어 보기 = ‘배우A 조각 12개’ 하이라이트
- **하나로 저장**(합치기) / **각각 저장**(조각별 파일). 새 파일에 조각의 칩·메모·원본 구간이 따라가요 (로컬 서버)
- 영상 카드의 가위 배지, 정보 패널의 ‘보관함 조각’에서도 바로 보고 재생해요

**정리 도구**
- 다른 폴더로 이동/복사(Ctrl+Shift+M / C), 이름 일괄 변경(여러 개 선택 후 F2), 폴더 풀기(Ctrl+Shift+U)
- 날짜별 정리(Ctrl+Shift+D), 칩별 정리(Ctrl+Shift+G), 빈 폴더 정리

**중복 정리** (Ctrl+Alt+D, 지금 폴더는 Ctrl+Alt+Shift+D)
- 찾을 범위: 지금 보는 폴더 · 폴더 골라서(체크) · 전체 · **두 쪽 비교**(다운로드 ↔ 보관 폴더처럼, 양쪽에 걸친 것만) · 로컬 서버가 있으면 **다른 드라이브 폴더**(D:\ 등)
- 판정은 주인님 초안 그대로: 똑같은 파일(크기 → 앞뒤 1MB → 전체 해시), 같은 영상(길이가 거의 같고 5곳 장면 지문이 3곳 이상 일치). 길이 차이 0.3초 이내면 **확실**, 나머지는 **애매**로 나눠요
- 지문은 한 번 만들면 저장돼서 다음 검사는 새로 생긴·바뀐 파일만 봐요. ‘지문 미리 만들기’를 뒤에서 돌려 둘 수 있어요
- 보면서 확인: 나란히 보기, 장면 5곳 일치 표시, **두 영상 동시 재생**·A/B 전환, 키보드로 1/2 남길 것 · D 중복 아님 · X 이 파일 빼기 · Enter 정리
- 자유도: ‘중복 아님’은 기억해서 다시 안 보여요, 파일·폴더를 검사에서 빼기(제외 목록에서 되돌리기), 폴더마다 보관/정리 역할, 규칙 숫자 조정(바로 미리보기)
- 정리는 휴지통으로(다른 드라이브는 그 폴더의 `_중복정리`로). 지우기 직전에 남길 파일을 다시 확인하고, Ctrl+Z 한 번으로 모두 되돌려요

**안전**
- 지우면 앱 휴지통으로 가요(Ctrl+Shift+Backspace로 열기). 영구 삭제는 휴지통 안에서만
- **Ctrl+Z는 어느 화면에서든, 어떤 작업이든 한 번에 되돌려요.** 기록은 Ctrl+Alt+Z
- 정리 정보는 매일 자동 백업, 설정 › 데이터와 백업에서 다른 드라이브로 보조 백업

## 자주 쓰는 단축키

| 키 | 하는 일 | 키 | 하는 일 |
|---|---|---|---|
| Ctrl+K | 명령 팔레트(무엇이든 찾기) | ? | 모든 단축키 보기 |
| Ctrl+O | 작업 폴더 열기 | Ctrl+, | 설정 |
| Enter / Space | 크게 보기 / 훑어보기 | Delete | 휴지통으로 |
| F2 | 이름 바꾸기(여러 개면 일괄) | Ctrl+Alt+N | 새 폴더 |
| 1–9 | 칩 붙이기/떼기 | # | 칩 찾기 |
