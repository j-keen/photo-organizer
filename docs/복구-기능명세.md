## 2. 칩셋 (핵심 기능)
- **분류 → 칩 항목** 2단 구조. 분류를 만들고 그 안에 칩을 추가한다. ✅
- 만들어 둔 칩을 클릭 한 번으로 파일에 붙이거나 뗀다. ✅
- **선택형 분류**: 칩이 전부 펼쳐져 있어 바로 고른다. ✅
- **검색형 분류**: 항목이 많은 분류(예: 배우 이름)는 칩을 펼치지 않고 검색해서 고른다. ✅
- **2차 칩(하위 칩)**: 칩에서 + 버튼을 한 번 더 누르면 하위 칩을 만든다. 상위 칩을 골랐을 때만 하위 칩이 나타난다. 1차에서 끝내도 된다. ✅
- **칩셋 프리셋**: 용도별로 칩셋 구성을 저장해 두고 바꿔 쓴다. ✅
- 그 밖의 메모 기능은 필요 없다(주인님 말씀: "다른 것들은 필요 없었어").

### 칩셋 구현 메모
- 칩 정의: 작업 폴더의 `.fluid-organizer/chipsets.json` (브라우저 IndexedDB에도 사본). 사진 폴더와 같이 다니므로 브라우저를 다시 깔아도 남는다.
- 파일에 붙은 칩: 사이드카 `.txt`의 `#TAGS:` 줄에 `#분류/칩`, `#분류/칩/하위` 형태로 저장. 이름의 공백은 `_`로 바뀐다.
- 칩·분류 이름을 바꿔도 이미 칩을 붙인 파일은 예전 이름 그대로다.

## 3. 폴더 다루기

- 그리드 빈 곳 우클릭으로도 새 폴더 만들기 ❌ (지금은 New Folder 버튼만 있음)
- 드래그 앤 드롭으로 파일을 폴더에 넣기 ✅ / 폴더를 다른 폴더 안에 넣기 ❌

- 폴더 카드에 사진·영상 개수 표시 ❌, 폴더 썸네일 미리보기 🟡 (`getFolderPreviews` 있음)

## 주인님 추가 요구 (2026-10-19, 1라운드 중)
- 영상 썸네일: 모두 정지 썸네일로 보이고, **마우스를 올린 카드 하나만** 재생된다 (동시에 여러 개 재생 금지).
- 폴더 카드: **빈 폴더인지**, 안에 **사진·영상·폴더가 몇 개**인지, **전체 용량**이 얼마인지 보여 준다.
- 뷰어: 사진과 영상 모두 **회전 + 좌우 반전**, **Ctrl+휠로 확대·축소**.
- 삭제는 **소프트 삭제**(앱 휴지통)가 기본이다. 영구 삭제는 휴지통 안에서만.
- **Ctrl+Z는 어느 화면에서든, 어떤 기능이든 바로 되돌린다.** (코어: 전역 실행 취소, 정보 변경·파일 생성·덮어쓰기까지 되돌리기 지원 — 2026-10-19 반영)
