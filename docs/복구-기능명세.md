## 2. 칩셋 (핵심 기능)
- **분류 → 칩 항목** 2단 구조. 분류를 만들고 그 안에 칩을 추가한다. ❌
- 만들어 둔 칩을 클릭 한 번으로 파일에 붙이거나 뗀다. 🟡
- **선택형 분류**: 칩이 전부 펼쳐져 있어 바로 고른다. ❌
- **검색형 분류**: 항목이 많은 분류(예: 배우 이름)는 칩을 펼치지 않고 검색해서 고른다. ❌
- **2차 칩(하위 칩)**: 칩에서 + 버튼을 한 번 더 누르면 하위 칩을 만든다. 상위 칩을 골랐을 때만 하위 칩이 나타난다. 1차에서 끝내도 된다. ❌
- **칩셋 프리셋**: 용도별로 칩셋 구성을 저장해 두고 바꿔 쓴다. ❌
- 그 밖의 메모 기능은 필요 없다(주인님 말씀: "다른 것들은 필요 없었어").

## 3. 폴더 다루기
- 폴더 트리에서 우클릭 메뉴: 새 폴더, 이름 바꾸기, 삭제 등 기본 기능 ❌
- 그리드 빈 곳 우클릭으로도 새 폴더 만들기 ❌ (지금은 New Folder 버튼만 있음)
- 드래그 앤 드롭으로 파일을 폴더에 넣기 ✅ / 폴더를 다른 폴더 안에 넣기 ❌
- 폴더 풀기(안의 파일을 한 단계 위로 빼고 폴더 정리) ❌
- 폴더 카드에 사진·영상 개수 표시 ❌, 폴더 썸네일 미리보기 🟡 (`getFolderPreviews` 있음)

## 4. 영상
